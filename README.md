# Web Scraper

This project is a simple web scraper built using Python.

The program extracts book titles and prices from a website and stores the data in a CSV file.

## Features
- Scrapes book titles
- Scrapes prices
- Stores data in CSV format
- Displays extracted data in terminal

## Modules Used
- requests
- BeautifulSoup
- csv

## Technologies Used
- Python
- VS Code

## How It Works
1. Sends request to website
2. Reads HTML content
3. Extracts required data
4. Stores data in CSV file

## Output
Structured book data is extracted and saved successfully.
